## 🎭 动画效果

### 过渡动画

**缓动函数：**
- 标准：`ease` (0.3s)
- 平滑：`cubic-bezier(0.4, 0, 0.2, 1)` (0.4s)

**常用动画：**
1. **淡入** (`fadeIn`)
2. **上滑淡入** (`fadeInUp`)
3. **下滑淡入** (`fadeInDown`)
4. **左滑入** (`slideInLeft`)
5. **右滑入** (`slideInRight`)
6. **缩放入** (`scaleIn`)
7. **脉冲** (`pulse`)
8. **浮动** (`float`)
9. **弹跳** (`bounce`)
10. **闪烁** (`shimmer`)

### 交互动画

- 悬停上浮：`translateY(-2px ~ -12px)`
- 悬停缩放：`scale(1.02 ~ 1.1)`
- 点击反馈：`scale(0.95)`
- 旋转：`rotate(360deg)`

---

## 📱 响应式设计

### 断点

- **超小屏**：< 576px（手机竖屏）
- **小屏**：576px - 768px（手机横屏）
- **中屏**：768px - 992px（平板）
- **大屏**：992px - 1200px（小桌面）
- **超大屏**：> 1200px（大桌面）

### 适配策略

1. **导航栏**：移动端折叠为汉堡菜单
2. **电影网格**：自动调整列数（4列 → 3列 → 2列 → 1列）
3. **表单**：移动端全宽
4. **对话框**：移动端全屏
5. **字体**：移动端缩小

## 🚀 性能优化

### CSS优化

- 使用 `transform` 和 `opacity` 实现动画（GPU加速）
- 避免使用 `box-shadow` 动画（改用 `transform`）
- 使用 `will-change` 提示浏览器优化

### 图片优化

- 海报懒加载（待实现）
- 响应式图片（待实现）
- WebP格式支持（待实现）

### 动画优化

- 使用 `prefers-reduced-motion` 支持无障碍
- 避免过度动画
- 合理使用 `animation-delay`

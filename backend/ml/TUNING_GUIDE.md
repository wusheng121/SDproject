# 矩阵分解模型调参指南

## 一、关键指标解读

### 1. RMSE（均方根误差）
- **含义**：预测评分与真实评分的差距（越小越好）
- **MovieLens 基准**：
  - 优秀：< 0.85
  - 良好：0.85 ~ 0.95
  - 合格：0.95 ~ 1.05
  - 需改进：> 1.05

### 2. MAE（平均绝对误差）
- **含义**：预测误差的平均值（越小越好）
- **基准**：
  - 优秀：< 0.65
  - 良好：0.65 ~ 0.75
  - 合格：0.75 ~ 0.85
  - 需改进：> 0.85

### 3. 过拟合程度
- **计算**：`(测试集RMSE - 训练集RMSE) / 训练集RMSE × 100%`
- **判断**：
  - < 20%：过拟合程度低 ✓
  - 20% ~ 50%：轻度过拟合 ⚠
  - \> 50%：严重过拟合 ⚠⚠

### 4. 覆盖率
- **用户覆盖率**：测试集中多少用户在训练集中出现过
- **物品覆盖率**：测试集中多少电影在训练集中出现过
- **理想状态**：> 80%（低于此值说明冷启动问题严重）

## 二、超参数调优策略

### 参数 1：n_factors（隐因子数量）

**作用**：控制模型的复杂度和表达能力

- **增大 n_factors**（如 20 → 50 → 100）：
  - ✓ 提升模型表达能力
  - ✓ 可能降低训练集误差
  - ✗ 容易过拟合
  - ✗ 训练时间增加

- **减少 n_factors**（如 100 → 50 → 20）：
  - ✓ 降低过拟合风险
  - ✓ 训练速度更快
  - ✗ 模型表达能力下降
  - ✗ 可能欠拟合

**建议范围**：20 ~ 100（课程项目推荐 30 ~ 60）

---

### 参数 2：reg（正则化系数）

**作用**：防止过拟合

- **增大 reg**（如 0.01 → 0.05 → 0.1）：
  - ✓ 降低过拟合
  - ✓ 模型更泛化
  - ✗ 可能欠拟合
  - ✗ 训练集误差增大

- **减少 reg**（如 0.1 → 0.02 → 0.005）：
  - ✓ 降低训练集误差
  - ✓ 模型更贴合数据
  - ✗ 容易过拟合

**建议范围**：0.01 ~ 0.1

---

### 参数 3：n_epochs（训练轮数）

**作用**：控制训练充分程度

- **增加 n_epochs**（如 10 → 20 → 30）：
  - ✓ 模型收敛更充分
  - ✗ 训练时间增加
  - ✗ 可能过拟合（如果已收敛）

- **减少 n_epochs**：
  - ✓ 训练速度快
  - ✗ 可能未充分收敛

**建议**：观察训练过程中的 Train RMSE，如果已不再下降则无需增加

**建议范围**：10 ~ 30

---

### 参数 4：learning_rate（学习率）

**作用**：控制参数更新步长

- **增大 learning_rate**（如 0.005 → 0.01 → 0.05）：
  - ✓ 收敛速度快
  - ✗ 可能震荡/不稳定

- **减少 learning_rate**：
  - ✓ 训练更稳定
  - ✗ 收敛慢

**建议范围**：0.005 ~ 0.02（一般用 0.01 即可）

---

## 三、调参实战案例

### 案例 1：严重过拟合（如你当前的模型）

**症状**：
- 训练集 RMSE: 0.3941
- 测试集 RMSE: 1.1277
- 过拟合程度: 186.1%

**诊断**：模型过度拟合训练数据，泛化能力差

**解决方案**：
1. **减少隐因子数量**：`--n-factors 10` 或 `--n-factors 15`
2. **增加正则化**：`--reg 0.05` 或 `--reg 0.1`
3. **两者结合**：`--n-factors 15 --reg 0.05`

**预期效果**：训练集 RMSE 会升高，但测试集 RMSE 应下降

---

### 案例 2：欠拟合

**症状**：
- 训练集 RMSE: 1.2
- 测试集 RMSE: 1.25
- 过拟合程度: 4%

**诊断**：模型表达能力不足

**解决方案**：
1. **增加隐因子数量**：`--n-factors 100`
2. **减少正则化**：`--reg 0.01`
3. **增加训练轮数**：`--n-epochs 30`

---

### 案例 3：理想状态

**症状**：
- 训练集 RMSE: 0.75
- 测试集 RMSE: 0.88
- 过拟合程度: 17.3%

**诊断**：模型表现良好，泛化能力强

**可选优化**：微调参数寻找更优解

## 五、常见问题

### Q1：用户覆盖率很低（如 9.5%）怎么办？
**原因**：测试集中很多用户在训练集中没出现（冷启动问题）

**解决**：
- 数据划分时按用户分层采样（确保每个用户的评分在训练/测试集都有）
- 或者接受低覆盖率，对新用户使用内容推荐/热门推荐兜底

### Q2：训练很慢怎么办？
- 减少 `n_factors`（如 100 → 50）
- 减少 `n_epochs`（如 30 → 15）
- 使用更小的数据集快速验证

### Q3：如何判断模型已经足够好？
- 测试集 RMSE < 0.95（良好以上）
- 过拟合程度 < 30%
- 能满足业务需求（如推荐准确率、用户满意度）

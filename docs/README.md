## 2. 实现设计

| 文档 | 说明 |
|---|---|

需求 ER 与实现 ER 的关系：

- 需求 ER 描述业务核心模型，保持稳定。
- 实现 ER 增加会话、API Key、验证 token、审计日志、购物车、评价等生产支撑表。
- 生产支撑表不改变需求中的业务实体和核心流程。

## 5. 数据库同步规则

- 表结构：提交 Alembic 迁移，其他成员执行 `flask --app app db upgrade`。
- 演示/字典数据：写入 `backend/seed/init_products.py`，执行 `flask --app app seed-demo`。
- 真实数据：使用 `mysqldump` 或共享开发数据库，不提交 Git。
- 不提交 `*.db`、MySQL 数据目录、`.env`、`.sql` 数据快照。

## 二、直接可用的文档内容（按你的项目填好）

### 1. 项目背景
校园二手交易平台存在信息分散、发布麻烦、买家找不到合适商品的问题。本项目在普通二手平台基础上，引入 AI 拍照识物辅助发布、智能推荐提升匹配效率，并预留 Agent-Skill-MCP 能力，做成一个 Web 前后端分离的中等规模业务系统。

### 2. 用户角色与权限（RBAC）
三种角色：
- 普通用户：注册、登录、发布商品、浏览、搜索、下单、评价
- 平台管理员：管理用户、审核/下架商品、查看日志
- Agent 服务账号：通过 Skill 调用商品查询、推荐查询，只读

五张表：user / role / permission / user_role / role_permission  
密码 BCrypt 加密，手机号脱敏返回。

### 3. 功能性需求（8 条 user story）
1. 作为普通用户，我可以注册、登录、维护个人信息。
2. 作为普通用户，我可以拍照识物，自动填充商品品类、品牌、成色。
3. 作为普通用户，我可以发布、编辑、下架自己的商品。
4. 作为普通用户，我可以浏览、搜索商品，并用自然语言筛选。
5. 作为普通用户，我可以查看首页个性化推荐和商品详情相似推荐。
6. 作为普通用户，我可以加入购物车、创建订单、模拟支付、评价。
7. 作为平台管理员，我可以管理用户、审核/下架违规商品、查看操作日志。
8. 作为 Agent 服务账号，我可以通过 Skill 查询商品与推荐结果，且只能查询不能修改删除。

### 4. 非功能性需求（至少 5 条）
- 安全：密码 BCrypt 加密存储，接口手机号脱敏
- 性能：页面响应时间小于 2 秒
- 兼容：支持主流浏览器
- 安全：密码传输使用 HTTPS
- 安全：记录管理员与 Agent 关键操作日志

### 5. 三条业务线
- 业务线1：用户账号（注册、登录、个人信息、角色权限）
- 业务线2：商品发布与识物（拍照识物 → 自动填充 → 发布/编辑/下架）
- 业务线3：商品浏览与推荐（浏览、搜索、自然语言筛选、智能推荐、下单、评价）

### 6. 推荐模块设计思路（重点写）
- 推荐目标：首页猜你喜欢、商品详情相似推荐、搜索页个性化排序
- 数据来源：浏览、收藏、加购、下单、评价
- 算法设计：
  - 内容推荐：基于品类、品牌、成色、价格区间推荐相似商品
  - 协同过滤：基于用户-商品行为矩阵，找相似用户推荐
  - 矩阵分解：用隐向量预测用户偏好
  - 混合策略：冷启动用内容推荐，数据充足后用协同过滤 + 矩阵分解
- 冷启动：新用户推热门商品，新商品推内容相似
- 评价指标：准确率、召回率、覆盖率

### 7. 用例图（文字版，画图直接抄）
参与者：普通用户、平台管理员、Agent 服务账号  
普通用户用例：注册、登录、拍照识物、发布商品、浏览商品、搜索、自然语言筛选、查看推荐、下单、评价  
管理员用例：登录后台、管理用户、审核商品、查看日志  
Agent 用例：商品查询、推荐查询

### 8. 页面原型说明
- 注册页：账号、手机号、密码、验证码
- 登录页：账号密码登录、验证码登录切换
- 首页：推荐商品流
- 商品详情页：商品信息 + 相似推荐
- 发布页：拍照识物自动填充表单
- 管理后台：用户管理、商品审核、日志查看

### 9. Agent-Skill-MCP 方案（简要小节）
- Skill 清单：商品识别、商品查询、自然语言筛选、推荐查询
- 安全约束：独立服务账号、只读权限、操作留痕、参数强校验
- MCP 报文：服务账号、skillId、入参、时间戳、错误码
- 流程图：用户 → Agent → MCP → Skill → 业务 API → 数据库

### 10. 范围裁剪
第一版不做：真实电商 API 比价、真实支付、即时聊天、复杂风控、完整 MCP 协议实现、移动端 App。

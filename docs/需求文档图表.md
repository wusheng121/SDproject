## 图3：推荐算法流程图（Recommendation Algorithm Flow）

### Mermaid代码

```mermaid
flowchart TD
    Start([用户请求推荐]) --> Check{检查用户状态}
    
    Check -->|未登录| Strategy0[策略0:<br/>返回全局热门商品]
    Strategy0 --> End0[按热度排序返回]
    
    Check -->|已登录| GetBehavior[获取用户行为数据]
    GetBehavior --> CountBehavior{统计行为数量}
    
    CountBehavior -->|行为数=0| CheckPref{检查偏好设置}
    CheckPref -->|无偏好| StrategyA[策略A:<br/>全局热门推荐]
    CheckPref -->|有偏好| StrategyB[策略B:<br/>基于内容推荐]
    
    StrategyA --> QueryHot[查询热门商品<br/>按behavior_count排序]
    QueryHot --> ReturnA[返回Top N]
    
    StrategyB --> QueryCategory[查询偏好品类商品<br/>按评分排序]
    QueryCategory --> ReturnB[返回Top N]
    
    CountBehavior -->|0<行为数<10| StrategyC[策略C:<br/>轻量混合推荐]
    StrategyC --> Mix1[70%偏好品类高分商品]
    StrategyC --> Mix2[30%历史行为相似商品]
    Mix1 --> Merge1[合并去重]
    Mix2 --> Merge1
    Merge1 --> ReturnC[返回Top N]
    
    CountBehavior -->|行为数>=10| StrategyD[策略D:<br/>ML模型推荐]
    StrategyD --> BuildMatrix[构建用户-商品<br/>行为矩阵]
    BuildMatrix --> ALS[ALS矩阵分解<br/>预测评分]
    ALS --> CBFilter[内容过滤<br/>品类/价格相似度]
    CBFilter --> HybridScore[混合打分:<br/>60%协同+40%内容]
    HybridScore --> ReturnD[返回Top N]
    
    ReturnA --> AddReason[添加推荐理由]
    ReturnB --> AddReason
    ReturnC --> AddReason
    ReturnD --> AddReason
    End0 --> AddReason
    
    AddReason --> LogBehavior[记录推荐日志]
    LogBehavior --> End([返回推荐结果])
    
    style Start fill:#e1f5ff
    style Strategy0 fill:#ffe1e1
    style StrategyA fill:#ffe1e1
    style StrategyB fill:#fff4e1
    style StrategyC fill:#e1ffe1
    style StrategyD fill:#f0e1ff
    style End fill:#e1f5ff
```

## 图5：Agent-Skill-MCP交互流程图

### Mermaid代码

```mermaid
sequenceDiagram
    participant User as 用户/AI助手
    participant Agent as Agent服务
    participant MCP as MCP协议层
    participant Skill as Skill能力层
    participant API as 业务API
    participant DB as 数据库
    
    User->>Agent: 1. 发起请求<br/>"帮我找300元以内的手机"
    Agent->>Agent: 2. 解析意图<br/>提取关键信息
    
    Agent->>MCP: 3. MCP请求<br/>{skill: "product_query",<br/>params: {...}}
    
    MCP->>MCP: 4. 验证权限<br/>检查Agent账号权限
    
    MCP->>Skill: 5. 调用Skill<br/>商品查询能力
    
    Skill->>Skill: 6. 参数校验<br/>安全检查
    
    Skill->>API: 7. 调用业务API<br/>GET /api/products?...
    
    API->>API: 8. RBAC权限检查<br/>验证只读权限
    
    API->>DB: 9. 查询数据<br/>SELECT * FROM products...
    
    DB-->>API: 10. 返回结果
    
    API->>API: 11. 数据脱敏<br/>隐藏敏感信息
    
    API-->>Skill: 12. 返回商品列表
    
    Skill->>Skill: 13. 记录操作日志<br/>trace_id, 时间戳
    
    Skill-->>MCP: 14. 返回结果<br/>{code: 0, data: [...]}
    
    MCP-->>Agent: 15. MCP响应
    
    Agent->>Agent: 16. 格式化输出<br/>生成自然语言
    
    Agent-->>User: 17. 返回结果<br/>"找到5款符合条件的手机..."
    
    Note over MCP,API: 安全约束:<br/>1. 只读权限<br/>2. 操作留痕<br/>3. 参数强校验<br/>4. 独立账号
```

## 使用说明

### 方式1：在线渲染（推荐）

1. **PlantUML用例图**
   - 访问：https://www.planttext.com/
   - 复制上面的PlantUML代码
   - 点击"Generate"生成图片
   - 右键保存图片

2. **Mermaid图表**
   - 访问：https://mermaid.live/
   - 复制对应的Mermaid代码
   - 自动渲染
   - 点击右上角下载PNG/SVG

### 方式2：本地工具

1. **VS Code插件**
   - 安装 "PlantUML" 插件
   - 安装 "Markdown Preview Mermaid Support" 插件
   - 创建 `.puml` 或 `.md` 文件
   - 预览并导出

2. **命令行工具**
   ```bash
   # PlantUML
   java -jar plantuml.jar diagram.puml
   
   # Mermaid
   mmdc -i diagram.mmd -o diagram.png
   ```

### 方式3：在线美化工具

生成后可以用这些工具美化：
- **Figma** - 专业设计工具
- **Canva** - 快速美化
- **ProcessOn** - 在线绘图
- **Draw.io** - 免费开源
